# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in TriceraSync Engine or associated specifications, please report it responsibly.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to:
`security@traxdinosaur.com` (or create a private GitHub Security Advisory).

Please include:
- A description of the issue and affected components
- Step-by-step reproduction instructions or proof-of-concept
- Device model and Android version tested
- Potential impact of the vulnerability

### Response Timeline

- **Initial acknowledgment**: Within 48 hours.
- **Triage and assessment**: Within 5 business days.
- **Fix and disclosure**: Coordinated release schedule following verification.
